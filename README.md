# RTL Practice

SystemVerilog practice modules với testbench tương ứng.

## Nội dung
- `and_gate`, `mux` — combinational logic
- `dff`, `register`, `counter` — sequential logic
- `fsm`, `togglefsm`, `trafficpro`, `seqdetec` — FSM
- `alu1bit` — ALU
- `fifo` — FIFO buffer
- `uart` — UART protocol
- `edgedetector`, `button` — edge detection

## Tool
- Simulator: ModelSim
- Language: SystemVerilog
